# ES6 Data Manipulation

## Description
This project covers data manipulation concepts in ES6 JavaScript, including methods like `map`, `filter`, and `reduce`, typed arrays, and data structures such as `Set`, `Map`, and `WeakMap`.

## Learning Objectives
By the end of this project, you should be able to explain:
- How to use `map`, `filter`, and `reduce` on arrays
- How to work with Typed arrays
- How to use `Set`, `Map`, and `WeakMap` data structures

## Requirements
- Executed on **Ubuntu 20.04 LTS** using **Node.js 20.x.x** and **npm 9.x.x**
- Code tested using **Jest** (`npm run test`)
- Code style verified using **ESLint** (`npm run lint`)
- All functions are exported using ES6 module syntax

## Tasks Summary
| File | Description |
| --- | --- |
| `0-get_list_students.js` | Returns an array of student objects. |
| `1-get_list_student_ids.js` | Returns an array of student IDs using `map`. |
| `2-get_students_by_loc.js` | Filters students by location using `filter`. |
| `3-get_ids_sum.js` | Returns the sum of all student IDs using `reduce`. |
| `4-update_grade_by_city.js` | Combines `filter` and `map` to update student grades. |
| `5-typed_arrays.js` | Creates an Int8 typed array inside an ArrayBuffer. |
| `6-set.js` | Creates a `Set` from an array. |
| `7-has_array_values.js` | Checks if all array elements exist in a `Set`. |
| `8-clean_set.js` | Returns a string of `Set` values starting with a specific string. |
| `9-groceries_list.js` | Creates a `Map` containing grocery items and quantities. |
| `10-update_uniq_items.js` | Updates quantities in a `Map` for items with quantity 1. |
| `100-weak.js` | Uses a `WeakMap` to track API query calls and limit load. |
