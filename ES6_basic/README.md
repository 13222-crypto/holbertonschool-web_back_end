# ES6 Basics

## Description
This project covers the fundamentals of ECMAScript 2015 (ES6) JavaScript features, including block-scoped variables, arrow functions, template literals, default parameters, rest and spread syntax, and object shorthand properties.

## Requirements
- All files will be executed on Ubuntu 20.04 LTS using **Node.js** (version 20.x.x) and **npm** (version 9.x.x).
- Code is styled using **ESLint** (Airbnb configuration) and tested using the **Jest** framework.
- All functions must be exported.
- All JavaScript files must use the `.js` extension and end with a new line.
