# NoSQL - MongoDB Project

## Description
This project covers MongoDB fundamentals including database management, CRUD operations using MongoDB Shell, and interacting with MongoDB using Python (`pymongo`).

## Requirements
* Shell scripts evaluated on Ubuntu 20.04 LTS with MongoDB 3.6.3.
* Python scripts interpreted using Python 3.9 and `pymongo`.
* Python files compliant with `pycodestyle` (version 2.5.*).
* All Python modules and functions have clear documentation.

## Tasks
* **0-list_databases:** List all databases in MongoDB.
* **1-use_or_create_database:** Create or switch to `my_db`.
* **2-insert:** Insert a document into `school` collection.
* **3-all:** List all documents in `school` collection.
* **4-match:** List matching documents in `school` collection.
* **5-count:** Display count of documents in `school` collection.
* **6-update:** Update documents in `school` collection.
* **7-delete:** Delete matching documents from `school` collection.
* **8-all.py:** Python function to list all documents in a collection.
* **9-insert_school.py:** Python function to insert a document based on `kwargs`.
* **10-update_topics.py:** Python function to update document topics by name.
