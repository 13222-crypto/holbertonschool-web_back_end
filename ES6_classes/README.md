# ES6 Classes

## Description
This project focuses on ECMAScript 2015 (ES6) classes in JavaScript. It covers class definition, getters, setters, static methods, inheritance, metaprogramming, and built-in symbols.

## Requirements
- All code interpreted/compiled on Ubuntu 20.04 LTS using Node.js (v20.x.x) and npm (v9.x.x or v10.x.x).
- All files end with a new line.
- Code style is enforced using ESLint.
- Code is tested using Jest.
