# Pagination Project

## Description
This project focuses on implementing various pagination strategies in Python. Pagination is used to divide a large dataset into discrete pages to improve efficiency, response time, and user experience when retrieving data.

## Learning Objectives
By completing this project, you will be able to explain:
* How to paginate a dataset with simple `page` and `page_size` parameters.
* How to paginate a dataset with hypermedia metadata (HATEOAS).
* How to implement pagination in a deletion-resilient manner.

## Requirements
* All files interpreted/compiled on Ubuntu 20.04 LTS using `python3` (version 3.9).
* Code style complies with `pycodestyle` (version 2.5.*).
* All modules and functions are fully documented with clear sentences.
* All functions have type annotations.
* Standard dataset used: `Popular_Baby_Names.csv`.

## Tasks Summary
